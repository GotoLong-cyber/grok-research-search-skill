# 技能总索引

## 当前收录

| 技能目录 | 用途 | 配置变量 | 输出目录 | 风险提醒 |
|---|---|---|---|---|
| `grok-research-search/` | 使用第三方中转站 Grok API 做科研检索、related work 检索、方法进展检索、最新信息检索和候选参考文献整理 | `GROK_API_KEY`、`GROK_BASE_URL`、`GROK_MODEL` | `outputs/Grok检索报告/` 与 `outputs/Grok检索报告/候选文献表/` | 候选文献不能直接当事实，必须人工核验 DOI、期刊、年份和 BibTeX；不得写入或输出 API key |

## grok-research-search 使用提醒

- 入口文件：`grok-research-search/SKILL.md`
- 脚本文件：`grok-research-search/scripts/grok_search.py`
- 支持模式：`literature`、`related_work`、`method`、`api`
- 第三方中转站默认推荐：`--backend raw`
- `GROK_MODEL` 缺失时默认 `grok-4.20-fast`
- `GROK_API_KEY` 缺失时可 fallback 使用 `XAI_API_KEY`
- `GROK_BASE_URL` 必须显式配置，且不能写死在代码里
- `--diagnose` 中如果 `/models` 与 `/chat/completions` 返回 `HTTP 200`，但 `chat content is OK: no`，不一定影响主检索；只要真实检索能正常落地 markdown 报告和 CSV，即可继续使用
- 若中转站不支持实时搜索，报告中必须注明：`本次结果来自模型回答，需人工核验，不保证实时联网检索`

## 统一风险提醒

- 所有 Grok 检索结果只可作为候选线索，不直接改论文正文
- 所有候选文献进入参考文献池前必须人工核验
- 不要覆盖已有报告，不要写入任何真实 API key
