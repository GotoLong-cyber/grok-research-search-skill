# Grok科研检索模板

统一提醒：

`候选文献，需人工核验 DOI、期刊、年份和 BibTeX`

第三方中转站推荐：

```bash
python .claude/skills/grok-research-search/scripts/grok_search.py "你的检索问题" --mode literature --max-items 10 --backend raw
```

补充说明：

- 对第三方中转站，默认优先使用 `--backend raw`
- `--diagnose` 中如果 `/models` 和 `/chat/completions` 都返回 `HTTP 200`，但 `chat content is OK: no` 或预览为空，不一定影响主检索
- 更重要的是确认真实检索能否成功生成 markdown 报告和 CSV

## 1. 检索近两年顶刊 SCI

```text
请检索近两年与[主题]直接相关的 SCI 顶刊或公认高影响期刊论文，优先给出候选文献、期刊、年份、DOI、方法关键词、与本文的关系，并指出哪些信息需要人工核验。
```

## 2. 检索 retrieval-augmented forecasting

```text
请检索 retrieval-augmented forecasting 相关论文，重点找时间序列预测、邻居检索、检索增强推理、latent retrieval、state-aware retrieval 等方向的代表性工作，并按“可作 related work / 可作 discussion / 仅启发思路”分类。
```

## 3. 检索 KNN 与可靠性估计

```text
请检索 KNN、neighbor reliability estimation、confidence estimation、support score、uncertainty-aware retrieval 与预测建模相关的候选论文，并说明哪些论文更适合支撑“可靠性估计只做 refinement 而不是主预测器”这一叙事。
```

## 4. 检索跨工况刀具磨损预测

```text
请检索跨工况刀具磨损预测、跨域刀具磨损建模、工况迁移、domain shift、few-shot adaptation、cross-condition tool wear prediction 相关候选论文，优先给出近年方法进展与可直接对照的 baselines。
```

## 5. 检索可模仿论文 story

```text
请检索与“状态语义检索纠偏”叙事相近、结构可模仿的论文。重点寻找“先指出 naive retrieval 失效，再提出 state-aware retrieval correction，最后把 reliability 机制降格为 refinement”的写作路径样例。
```

## 6. 检索 related work 候选

```text
请为论文 related work 检索候选文献，分成以下几组：1) retrieval-based forecasting；2) latent-state retrieval；3) reliability / support estimation；4) cross-condition tool wear prediction。每组给出代表性候选及为何相关。
```

## 7. 检索 discussion 支撑文献

```text
请检索可用于 discussion 的支撑文献，重点回答：为什么 same-time 不等于 same-state；为什么 latent representation 更适合做状态语义检索；为什么 support-based gating 更适合作为可靠性修正而不是主预测主线。
```
