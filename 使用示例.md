# 使用示例

## 1. 查看帮助

```bash
python .claude/skills/grok-research-search/scripts/grok_search.py --help
```

## 2. 诊断环境变量和 API 可达性

```bash
python .claude/skills/grok-research-search/scripts/grok_search.py --diagnose
```

## 3. 检索近两年 SCI 候选论文

```bash
python .claude/skills/grok-research-search/scripts/grok_search.py \
"recent SCI papers on tool wear prediction domain adaptation" \
--mode literature \
--max-items 5 \
--backend raw
```

## 4. 检索 related work 候选

```bash
python .claude/skills/grok-research-search/scripts/grok_search.py \
"retrieval-augmented forecasting related work for time series prediction" \
--mode related_work \
--max-items 10 \
--backend raw
```

## 5. 使用纯英文文件名

```bash
python .claude/skills/grok-research-search/scripts/grok_search.py \
"recent SCI papers on tool wear prediction domain adaptation" \
--mode literature \
--max-items 5 \
--backend raw \
--ascii-filenames
```
